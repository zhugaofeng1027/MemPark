# Multimodal Memory / 多模态记忆

[返回项目主页](../README.md#research)

## 研究定位

探索如何把文本、图像、音频和视频中的观察组织成可关联、可检索、可追溯的共同经历，保留各模态独有的信息，支持跨模态查询与长期事件理解。

本页为研究方向占位，具体方法与论文后续补充。

## 目标能力

| 能力 | 研究问题 |
| :--- | :--- |
| 多模态记忆表示 | 如何关联原始媒体、语义表示、来源与时间范围？ |
| 事件与时间对齐 | 如何把图像帧、语音、文本和视频片段绑定到共同事件？ |
| 跨模态检索 | 如何从一种模态的查询中找到其他模态的相关证据？ |
| 长时序记忆 | 如何在压缩长期观察时保留关键事件与细节？ |
| 证据回溯与冲突处理 | 如何定位原始证据，并处理模态间的不一致？ |

## 与其他方向的协同

- **共享核心**：统一管理模态类型、证据引用和检索入口。
- **结构化记忆**：通过实体、事件和时间组织跨模态联系。
- **自进化记忆**：根据新增证据修正对齐结果、摘要与事件解释。
