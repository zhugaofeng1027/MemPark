# Structured Memory / 结构化记忆

[返回项目主页](../README.md#research)

## 研究定位

探索如何把分散的记忆片段组织为具有实体、事件、时间和关系的结构，在保持细节绑定的同时形成更高层次的抽象，支持长期任务中的检索与推理。

本页为研究方向占位，具体方法与论文后续补充。

## 目标能力

| 能力 | 研究问题 |
| :--- | :--- |
| 事件级表示 | 如何保存人物、行为、对象、时间和来源之间的绑定？ |
| 实体与关系关联 | 如何连接同一实体的跨事件经历，同时避免错误关联？ |
| 层次化组织 | 如何协调事实、事件、主题与长期知识之间的粒度？ |
| 时序与状态建模 | 如何表达事件顺序、状态变化与信息有效时间？ |
| 结构化检索与推理 | 如何结合语义、关系和时间约束召回可追溯的证据？ |

## 与其他方向的协同

- **共享核心**：使用统一记忆对象、来源标识和生命周期。
- **多模态记忆**：为不同模态的观察提供共同的事件和实体锚点。
- **自进化记忆**：允许结构随新证据进行合并、拆分、纠错和重组。
