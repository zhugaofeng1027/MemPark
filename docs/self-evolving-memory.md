# Self-Evolving Memory / 自进化记忆

[返回项目主页](../README.md#research)

## 研究定位

探索如何让记忆内容、组织方式及读写策略在持续交互中改进。这里的“自进化”不仅指新增记录，还包括基于证据的修正、经验抽象，以及经评测验证的策略调整。

本页为研究方向占位，具体方法与论文后续补充。

## 目标能力

| 能力 | 研究问题 |
| :--- | :--- |
| 记忆巩固 | 如何合并重复经历、形成稳定知识，同时保留必要细节？ |
| 冲突检测与修正 | 如何区分事实更新、来源冲突与错误记忆？ |
| 选择性遗忘 | 如何移除低价值或过时信息，避免丢失仍有效的知识？ |
| 经验反思 | 如何从成功与失败中提取可复用经验，而非放大错误？ |
| 读写策略演化 | 如何利用反馈改进写入、检索与更新决策？ |
| 演化追踪 | 如何记录更新依据、版本变化及演化前后的任务表现？ |

## 与其他方向的协同

- **共享核心**：依托统一的反馈入口、更新记录和版本机制。
- **结构化记忆**：调整记忆之间的关系、层次与组织粒度。
- **多模态记忆**：利用新增模态证据修正已有理解并保留证据链。
